The bus target in a block

The target of a [bus] link is an ordinary node, so it can be in a frame, a row or a column, with its own links. Two real layouts of the DMZ case show what that gives, and one thing the layout still has to be told.

1. In a zone of its own, beside the data zone

row {
  frame data "data zone, 10.0.3.0/24" { ... }
  frame mgmt "management, 10.0.9.0/24" [grey] {
    siem [monitor]: SIEM | log collection
    pager [bell]: Pager | on-call
  }
}
siem -> pager : alerts
fw1 -> siem [bus] : 514/udp
fw2 -> siem [bus] : 514/udp
fw3 -> siem [bus] : 514/udp

This is the case that works: the management zone is a normal frame in a row, the SIEM has a normal link (to the pager), so the layout knows where it goes. The bus runs beside the diagram and turns into the zone at the SIEM's height, crossing the zone border once.

2. Declared in a zone, with no ordinary link

frame dmz "DMZ, 10.0.1.0/24" [orange] {
  siem [monitor]: SIEM | log collection
  ...
}
fw1 -> siem [bus] : 514/udp
fw2 -> siem [bus] : 514/udp
fw3 -> siem [bus] : 514/udp

What goes wrong. The SIEM has no ordinary link, and the bus takes no part in the layout, so nothing tells the layout where it goes: it ended up outside its own zone, over the page. A bus target that has no other link must be placed by something.

The rule that fixes the second picture

  • A [bus] link takes no part in the layout except as a placement hint for a target with no other link: the target is then placed inside its own zone, after the nodes that tap into it, as if the first tap linked to it with the weakest possible weight. It never pulls the taps.
  • If you want it somewhere particular, a row, a column, a zone or align does it, as for any node.
  • The last leg of the bus, from the edge of the diagram to the target, runs along the target's own row and crosses zone borders at right angles. If a node is in the way, the leg takes the nearest free gap and hops the links it crosses; if there is none, the result carries a warning and the leg is drawn along the outer edge.
